# 🎭 Fasnet 2027 Salmendingen – Offizieller Webauftritt

Moderner, eleganter und responsiver Webauftritt für die **Fasnet 2027 in Salmendingen** (Elferrat Salmendingen), optimiert für **GitHub Pages**.

---

## 🌟 Funktionen

1. **Der Narrenfahrplan 2027 (`index.html`)**:
   - Vollständige Übersicht aller 10 Veranstaltungen und Termine der Fasnet 2027 (vom 11.11. bis zum Fasnetsdienstag).
   - Dynamischer Live-Countdown zum nächsten Highlight.
   - Kategorienfilter (Hauptfasnet, Umzüge, Tradition, Party, Kinder & Familie).
   - Kalender-Export (.ics): Jeden Termin einzeln oder alle Termine auf einmal mit 1 Klick ins eigene Smartphone / Outlook importieren.
   - Integrierter Konfetti-Effekt (Canvas Confetti).
   - Dezenter Floating-Audioplayer mit Salmendinger Hits (*Bella Salmendingen*, *Post geht ab*, *Fasnet Fieber*).
   - Historischer Rückblick auf die Flyer von 2026.

2. **Das Petz-Portal (`petzen.html`)**:
   - Motto: *„Jessas Jessas heidanei, s wird doch nix bassiert sei... oder doch?“*
   - Anonymes Formular für Geschichten, Missgeschicke und Dorfklatsch aus dem vergangenen Jahr.
   - Medien-Upload für Beweisfotos, Sprachnachrichten und Videos mit Live-Vorschau.
   - Großer **„Petzen“**-Button mit Jubel-Konfetti nach dem Absenden.

3. **Serverless Backend (Google Apps Script)**:
   - 100% kostenlos und ohne externe Hosting-Kosten für GitHub Pages.
   - Speichert hochgeladene Dateien direkt in Google Drive.
   - Schreibt Geschichten automatisch in ein Google Sheet.
   - Sendet Benachrichtigungen an Gmail.
   - Schnelle 2-Minuten-Einrichtung via [`backend/README_SETUP.md`](./backend/README_SETUP.md).

---

## 🚀 Hosting auf GitHub Pages aktivieren

1. Repository auf GitHub pushen.
2. Im GitHub Repository auf **Settings** > **Pages** gehen.
3. Unter **Source** den Branch `main` (bzw. `master`) und Ordner `/ (root)` auswählen.
4. Auf **Save** klicken. Innerhalb weniger Sekunden ist deine Website weltweit online erreichbar!
